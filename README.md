# Artale Market Dashboard

Real-time in-game market data and TradingView-style candlestick visualization for Artale.

## Live Dashboard
[https://gary1346aa.github.io/artale-market-dashboard/](https://gary1346aa.github.io/artale-market-dashboard/)

## Overview
- Interactive candlestick charts with volume bars
- Multi-timeframe aggregations (1-hour, 4-hour, 1-day)
- Order book active listings and trade execution history
- Automated periodic data updates
